# AgriN AI 🌾

AI-powered regenerative agricultural intelligence platform for India, designed for scalable BRICS cooperation.

## MVP
- Localised agro-advisory
- Regenerative farming recommendations
- Crop disease diagnosis
- Weather, soil and satellite intelligence
- Multilingual farmer-first UX
- BRICS interoperable architecture

## Platforms
Flutter single codebase for Web, Android, iOS and Windows.

## Development
```bash
flutter pub get
flutter run -d chrome
```
